# Handoff: лендинг «Персональная CRM»

## Overview
Одностраничный статичный лендинг. Единственное целевое действие — кнопка «Добавить контакты», ведущая в приложение (URL пока не задан → вынести в константу `APP_URL`). Кнопка встречается 2 раза (первый экран, финальный CTA) + 1 раз в шапке десктопа.

**Стек:** Astro (static output) + Tailwind CSS 4. Без JS на клиенте.

## About the Design Files
Файлы в `design/` — **HTML-референсы дизайна**, не продакшн-код. Задача — воссоздать их в Astro + Tailwind 4. Открываются в браузере напрямую (рядом лежит `support.js`, нужен только для просмотра).
- `design/landing-mobile.dc.html` — мобильная версия (макет 390 px)
- `design/landing-desktop.dc.html` — десктоп (контейнер 1320 px)
- `copy.md` — исходный текст. **Все тексты — дословно**, не редактировать.

## Fidelity
**High-fidelity.** Цвета, шрифты, размеры, отступы — финальные. Воспроизводить точно.

## Рекомендуемая структура
```
src/
  layouts/Base.astro          — <html lang="ru">, шрифты, meta
  pages/index.astro
  components/
    Header.astro
    Hero.astro                — + ContactCards
    ContactCards.astro        — 3 повёрнутые карточки людей
    Problem.astro
    Solution.astro
    Benefits.astro
    FinalCta.astro            — + футер-строка
    CtaButton.astro           — props: size ('md' | 'lg'), href = APP_URL
  styles/global.css           — @import "tailwindcss"; @theme {...}
```
Одна вёрстка, адаптив через брейкпоинты: мобильная раскладка по умолчанию, десктопная с `lg:` (1024px). Между 390 и 1024 — мобильная раскладка, растянутая по ширине (контент максимум ~560px по центру допустимо).

### 3. Проблема (крем)
Фон `cream`, текст `cobalt-700`, верхние радиусы.
- Mobile: padding 56px 24px 64px, column gap 22px.
- Desktop: grid 2 колонки, gap 56px 80px, padding 112px 56px. Слева H2, справа абзацы (column gap 28px, padding-top 12px).
- **H2:** «*«Надо бы написать»* — и снова проходит месяц» (курсив — «"Надо бы написать"» вместе с кавычками-ёлочками).
- Абзац 1 (цвет `cobalt-ink`): «С подругой давно собирались встретиться. С бывшим коллегой — выпить кофе. На мероприятии познакомились с интересным человеком, но его контакт затерялся среди переписок.»
- Разделитель 1px `cream-line`.
- Абзац 2: «Работа, дела и повседневные заботы забирают внимание. А общение с людьми, которым вы рады, всё чаще откладывается на потом.»

## Interactions & Behavior
- Все кнопки «Добавить контакты» — `<a href={APP_URL}>`. Hover: `opacity: .9`. Добавить видимый `focus-visible` outline (2px `cream`, offset 3px) — в макете не нарисован.
- Анимаций нет. Карточки статичны (повороты через `rotate-[-5deg]` и т.п.).
- Стрелка «→» в кнопке — текстовый символ, `aria-hidden`.
- Нет состояний, форм, загрузки данных.
